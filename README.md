# مسابقة نادي القرآن الكريم — ENSIAS 🌙

تطبيق ويب للمسابقة (عربي / RTL)، يعمل على الهواتف، مع مؤقّت زمني، تصحيح تلقائي،
حفظ إجابات كل مشارك في قاعدة بيانات، ولوحة أفضل 3 متصدّرين.

---

## كيف أشغّل التطبيق؟ / How to run

لا يحتاج أي تثبيت (يعمل بـ Node.js فقط، بدون npm):

```powershell
cd C:\Users\Lenovo\club-quran-quiz
node server.js
```

ثم افتح المتصفح على:

- على نفس الحاسوب: **http://localhost:3000**
- على الهواتف (نفس شبكة WiFi): **http://<عنوان-IP-للحاسوب>:3000**

### كيف أعرف عنوان IP الخاص بالحاسوب؟

```powershell
ipconfig
```

ابحث عن `IPv4 Address` (مثال: `192.168.1.15`)، ثم اطلب من المشاركين فتح
`http://192.168.1.15:3000` على هواتفهم.

> ملاحظة: إذا لم تفتح الهواتف الصفحة، اسمح لـ Node.js في جدار الحماية (Windows Firewall)
> أو شغّل الأمر: اسمح للمنفذ 3000.

## طريقة اللعب / How players use it

1. يُدخل كل مشارك اسمه.
2. تظهر 13 سؤالاً واحداً تلو الآخر، مع مؤقّت (30 ثانية لكل سؤال).
3. أسئلة الاختيار من متعدد: اضغط على الإجابة.
4. الأسئلة المفتوحة: اكتب الإجابة (التصحيح متسامح مع اختلاف الإملاء والتشكيل).
5. في النهاية تظهر نتيجته، ثم لوحة **أفضل 3 متصدّرين**.

### كيف تُحتسب النقاط؟
- كل إجابة صحيحة = 100 نقطة أساسية + حتى 100 نقطة إضافية حسب السرعة.
- عند التعادل في النقاط، الأسرع (مجموع الوقت الأقل) يتقدّم.

---

## أين تُحفظ الإجابات؟ / Where is data stored

كل المشاركين وإجاباتهم تُحفظ في:

```
data/players.json
```

لكل لاعب: الاسم، النقاط، عدد الإجابات الصحيحة، الوقت الكلي، وكل إجابة على حدة.

### لتصفير قاعدة البيانات قبل الحدث (حذف المشاركين السابقين):
استبدل محتوى `data/players.json` بـ:

```json
{
  "players": []
}
```
